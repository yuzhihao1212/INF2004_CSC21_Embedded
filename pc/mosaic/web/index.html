            Set up voice detection

            This teaches the system how loud the lecturer sounds in each area, so it can tell the lecturer and students apart.

            1. Ask everyone except the lecturer to stay quiet.
            2. The lecturer speaks normally for about 30 seconds.
            3. Keep the sensors where they are afterwards.

            Listening… Keep only the lecturer speaking.

              Done. Voice detection is set up for every area.

              Set the noise limit

              This tells the system how loud is too loud in each area. Above the limit, the area shows Excessive noise instead of Talking.

              1. Open a sound-meter app on a phone.
              2. Pick one steady sound you can play at dB, such as music or a recording of a busy room.
              3. Go to each area's sensor in turn. Each one takes about 10 seconds.
